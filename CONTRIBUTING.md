# Contributing to ABILIFY

Thank you for your interest in contributing to ABILIFY.

## Getting Started

1. Fork the repository.
2. Clone your fork to your local machine.
3. Create a new branch for your changes.
4. Make your changes and test them locally.
5. Commit your changes with a clear commit message.
6. Push your branch to your fork.
7. Open a pull request describing your changes.

## Contribution Guidelines

- Keep changes focused and relevant to the project.
- Follow the existing HTML, CSS, and JavaScript structure.
- Keep accessibility in mind when modifying user-facing features.
- Test changes before submitting a pull request.
- Use clear and descriptive commit messages.

## Reporting Issues

When reporting a problem, include:

- A clear description of the issue.
- Steps to reproduce it.
- The expected behavior.
- The actual behavior.
- Relevant screenshots or error messages when applicable.

Thank you for helping improve ABILIFY.
